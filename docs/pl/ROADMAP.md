## Wersja 2.3.2

**Planowana data wydania: zima 2027 roku.**

| Zmiana | Oczekiwany rezultat |
|---|---|
| Uruchomienie bez `option.cfg` | Otwieranie głównego menu interaktywnego zamiast natychmiastowego otwierania Configuration Editor |
| Parametry krótkie i długie | Dodanie odpowiednich postaci długich do parametrów krótkich oraz, gdzie to możliwe, postaci krótkich do parametrów długich |
| Format `devicelist.cfg` | Usunięcie zbędnego pola „znacznik urządzenia” |
| Nazwa w nawiasach | Uczynienie wyodrębniania opcjonalnym i umożliwienie korzystania z pełnej nazwy |
