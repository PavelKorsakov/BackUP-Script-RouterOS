## Version 2.3.2

**Geschätztes Veröffentlichungsdatum: Winter 2027.**

| Änderung | Geplantes Ergebnis |
|---|---|
| Start ohne `option.cfg` | Das interaktive Hauptmenü öffnen, statt sofort den Konfigurationseditor zu starten |
| Kurze und lange Optionen | Zu kurzen Optionen passende Langformen und, soweit möglich, zu langen Optionen passende Kurzformen ergänzen |
| Format `devicelist.cfg` | Das überflüssige Feld „Gerätemarker“ entfernen |
| Name in Klammern | Die Extraktion optional machen und alternativ die Verwendung des vollständigen Namens erlauben |
