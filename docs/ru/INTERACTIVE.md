# Интерактивный интерфейс

[Оглавление](../README_RU.md)

## Главное меню

Через главное меню можно настроить скрипт, снять резервные копии, подготовить список устройств или открыть встроенную справку. Для его вызова запустите:

```bash
mikrotik-backup.sh -i
```

| Пункт | Что открывается или выполняется |
|---|---|
| `1` | «Мастер резервного копирования» для работы с одним устройством |
| `2` | Пакетное резервное копирование по списку устройств |
| `3` | «Редактор конфигурации» для создания или изменения `option.cfg` |
| `4` | Справка по ключам CLI |
| `5` | Инструкция по использованию скрипта |
| `6` | Выход в консоль |

Пункт `2` появляется, когда в `devicelist.cfg` есть хотя бы одна пригодная запись. Если списка ещё нет или в нём нет подходящих устройств, этот пункт не показывается. Номера остальных пунктов остаются прежними.

После пакетного копирования будет показан результат, затем скрипт вернёт Вас в консоль.

*(N.B. Запуск без ключей не является вызовом главного меню. При отсутствии `option.cfg` или пригодных настроек в нём откроется «Редактор конфигурации», а при подготовленных настройках скрипт перейдёт к пакетному копированию.)*

## Управление

Перемещаемся по пунктам стрелками **вверх и вниз**, выбираем нужный пункт клавишей **Enter**. Если возле действия указан номер, его можно выбрать соответствующей цифровой клавишей.

В редакторе и мастере над списком показывается описание выбранного поля. Если все строки не помещаются в окне терминала, список прокручивается при перемещении стрелками. Заголовок и описание остаются видимыми, а выбранная строка не уходит за пределы окна.

Пункты сохранения, выполнения и выхода находятся в конце того же списка. Затемнённые строки недоступны при выбранных настройках и при перемещении пропускаются.

Для работы нужны терминал и утилита `stty`. И стандартный ввод, и стандартный вывод должны быть связаны с терминалом. Основные экраны рассчитаны на ширину не менее 46 колонок, встроенная инструкция требует 80. При недостаточном размере окна скрипт сообщит об ошибке `31`; увеличьте окно и повторите запуск.

## Редактор конфигурации

Открыть редактор можно через пункт `3` главного меню или непосредственно командой:

```bash
mikrotik-backup.sh -e
```

Если файл `option.cfg` уже подготовлен, форма будет заполнена Вашими настройками. Если файла ещё нет, используются значения «по умолчанию».

В редакторе выбираются язык, источник списка устройств, параметры резервных копий, хранилище, месячная архивация и журналирование. Назначение самих параметров и их значения описаны в [OPTIONS.md](OPTIONS.md).

### Изменение настроек

Переключатели «Да / Нет», тип резервной копии, формат экспорта и уровень журнала меняются нажатием **Enter** непосредственно в строке. Для пути или дня месячной архивации открывается ввод значения.

Поле «Использовать инкрементальное сравнение» (`UseIncremental`) расположено сразу после типа резервной копии. «Да» включает сравнение, «Нет» оставляет каждую новую исправную копию без сравнения с предыдущей.

Для месячной архивации укажите `false`, чтобы отключить её, либо число от `1` до `28`. В форме отключённое состояние показывается как «Нет», включённое как выбранное число месяца.

Поля, не относящиеся к выбранному варианту работы, затемняются. Например, при снятии только `.rsc` недоступны шифрование бинарной копии и очистки перед ней, а при выборе только `.backup` недоступны параметры текстового экспорта. При таком переключении неприменимые параметры сбрасываются к своим значениям по умолчанию.

Пароль шифрования вводится и показывается под звёздочками.

### Сохранение и отмена

Выбираем нужные параметры → переходим к «Сохранить» → нажимаем **Enter**. Файл `option.cfg` будет создан или перезаписан с выбранными настройками.

До сохранения изменения находятся только в памяти. Пункт «Отмена» оставляет прежний файл без изменений. Если Вы уже что-то поменяли, редактор попросит подтвердить отказ от этих изменений.

Редактор, открытый из главного меню, возвращает в него. При отдельном запуске через `-e` после закрытия редактора Вы возвращаетесь в консоль.

*(N.B. `SshPort`, `IgnoreOxiAccess`, `encrypt_type`, `Login` и `Password` в форме не показываются. Их настройка и правила сохранения разобраны в [OPTIONS.md](OPTIONS.md).)*

### Выбор языка

На строке языка каждое нажатие **Enter** переключает следующий вариант:

```text
auto → ru → en → найденные внешние языки по алфавиту → auto
```

Язык формы меняется сразу, чтобы можно было посмотреть результат. «Сохранить» записывает выбранный язык в `option.cfg`, отмена возвращает прежний язык интерфейса. Если при запуске явно указан `--language`, после выхода из редактора снова действует этот ключ.

Подключение внешних переводов описано в [LOCALIZATION.md](LOCALIZATION.md).

## Мастер резервного копирования

«Мастер резервного копирования», он же BackUP Master, позволяет заполнить параметры одного устройства, снять его копии, сохранить устройство в список или подготовить команду для запуска из консоли.

Выберите пункт `1` главного меню либо запустите:

```bash
mikrotik-backup.sh -b
```

В отличие от редактора конфигурации, мастер не заполняет обычные поля настройками из `option.cfg`. Они берутся из встроенных значений и параметров, явно переданных через CLI. Исключение составляет `UseIncremental`: его значение берётся из файла опций, а при отсутствии этой настройки используется `true`.

Существующие записи из `devicelist.cfg` в форму тоже не загружаются. Имя, адрес, логин и пароль заполняются для выбранного Вами устройства.

### Поля мастера

Поля расположены в следующем порядке. Здесь приведены их названия в русском интерфейсе:

| Поле | Назначение |
|---|---|
| Имя устройства | Имя для списка устройств и для резервных копий, если получение RouterOS Identity отключено |
| IP-адрес | IP-адрес или DNS-имя устройства |
| Логин | Пользователь устройства RouterOS |
| Пароль | Пароль устройства RouterOS |
| SSH-порт | Порт подключения; по умолчанию `22` |
| Тип резервной копии | Конфигурация `.rsc`, бинарная копия `.backup` или оба формата |
| Использовать инкрементальное сравнение | Сравнивать новую копию с предыдущей или сохранять без сравнения |
| Формат экспорта | `compact`, `terse` или `verbose` |
| Чувствительные данные | Включать чувствительные значения в текстовый экспорт |
| Пароль шифрования | Шифрование бинарной копии; пустое значение отключает шифрование |
| Очистка DNS-кэша | Очистить DNS-кэш перед бинарной копией |
| Очистка истории консоли | Очистить историю консоли перед бинарной копией |
| Каталог резервных копий | Каталог для сохранения файлов |
| Это сетевой каталог | Значение `UseNetFolder`; проверка монтирования применяется в пакетном режиме |
| Использовать RouterOS Identity | Получать имя с устройства вместо указанного в форме |

Переключатели, тип копии и формат экспорта меняются через **Enter**, остальные значения вводятся в соответствующих полях. Оба пароля скрыты звёздочками.

**Обратите внимание!!!**  
По умолчанию включены чувствительные данные в текстовом экспорте, очистка DNS-кэша и истории консоли перед бинарной копией. Перед выполнением выберите нужные Вам настройки.

Пунктов для `MonthlyArchive`, `LogLevel` и `MainLogPath` в мастере нет. Месячная архивация при выполнении через мастер отключена, а настройки журналирования берутся из `option.cfg` с учётом переданных CLI-параметров.

### 1. Выполнить резервное копирование

Заполняем адрес, логин и пароль, проверяем порт и параметры копии → выбираем «1. Выполнить резервное копирование».

При включённом получении RouterOS Identity имя для копий будет взято с устройства. Если эта возможность отключена, необходимо заполнить поле «Имя устройства».

Начнётся одиночное резервное копирование. По завершении будет показан результат с кодом, после чего скрипт вернёт Вас в консоль. В форму мастера он уже не возвращается, независимо от того, успешно прошло копирование или с ошибкой.

Расположение файлов и правила хранения описаны в [BACKUPS.md](BACKUPS.md), сообщения о выполнении в [LOGGING.md](LOGGING.md).

### 2. Сохранить устройство в devicelist.cfg

Для сохранения требуются имя устройства, адрес, логин, пароль и SSH-порт. Пока нужные поля не заполнены, соответствующее действие недоступно.

Мастер создаст файл, добавит новую запись или обновит существующую с тем же именем. При конфликте записей или ошибке сохранения прежний список остаётся без изменений. После сохранения форма остаётся открытой.

**Сохраняются только данные устройства в `devicelist.cfg`.** Параметры копирования из формы не записываются в `option.cfg`, само резервное копирование этим действием не запускается.

*(N.B. Порт `22` сохраняется пустым полем. При последующем пакетном запуске такая запись использует `SshPort` из настроек скрипта. Нестандартный порт записывается явно.)*

Формат списка и правила обновления описаны в [DEVICES.md](DEVICES.md).

### 3. Скопировать консольную команду

На основе заполненной формы мастер подготовит команду запуска и передаст её в буфер обмена. Резервное копирование не начнётся, а работа мастера завершится выходом в консоль.

Для этой возможности нужны GNU `base64` с поддержкой `--wrap=0` и поддержка OSC 52 Вашим терминалом. При работе через терминальный мультиплексор он также должен пропускать эту команду. Если передача в буфер не поддерживается, открытым текстом команда на экран не выводится.

Параметры, совпадающие со встроенными значениями, могут не включаться в команду. При её последующем запуске продолжают действовать настройки из `option.cfg`, поэтому результат может отличаться от выполнения непосредственно через мастер.

Настройка `UseIncremental` в команду не переносится: отдельного CLI-ключа для неё нет. При запуске скопированной команды она будет взята из `option.cfg` либо из значений по умолчанию.

*(N.B. Команда в буфере обмена содержит пароли. Учитывайте это при использовании истории буфера и вставке команды в оболочку. Подробности описаны в [SECURITY.md](SECURITY.md).)*

### 0. Вернуться в Главное меню

Результат зависит от того, откуда Вы открыли мастер:

| Способ открытия | Куда произойдёт возврат |
|---|---|
| Через главное меню `-i` | В главное меню |
| Отдельным запуском `-b` | В консоль |

Несохранённые параметры формы отбрасываются. Уже сохранённая запись в `devicelist.cfg` остаётся.

## Справка и инструкция

Пункт `4` главного меню открывает справку по ключам командной строки, а пункт `5` открывает краткую инструкцию по работе скрипта.

Если текст не помещается по высоте, он разбивается на страницы. Листаем клавишами **PageUp / PageDown**, номер текущей страницы показывается на экране.

Пункт `0` возвращает в главное меню, пункт `6` завершает работу скрипта. Эти действия можно выбрать стрелками и **Enter** либо соответствующей цифрой.

Ту же справку по CLI можно получить непосредственно в консоли:

```bash
mikrotik-backup.sh -h
```
