## Версия 2.3.2

**Ориентировочная дата релиза: зима 2027 года.**

| Изменение | Что должно получиться |
|---|---|
| Запуск без `option.cfg` | Открывается главное интерактивное меню, а не сразу «Редактор конфигурации» |
| Короткие и длинные ключи | У коротких ключей появляются соответствующие длинные формы, а у длинных, где возможно, короткие |
| Формат `devicelist.cfg` | Убирается ненужный «Маркер устройства» |
| Имя из круглых скобок | Извлечение становится опциональным, с возможностью использовать полное имя |
