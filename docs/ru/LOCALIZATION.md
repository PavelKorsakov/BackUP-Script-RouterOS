# Локализация

[Оглавление](../README_RU.md)

## Язык интерфейса и журналов

В скрипт встроены русский (`ru`) и английский (`en`) языки. Для них отдельные файлы перевода не нужны. Вместе с версией 2.3.1 поставляются внешние переводы интерфейса и журналов: `de.lang`, `es.lang`, `lv.lang`, `pl.lang` и `uk.lang`.

Язык, на котором написана документация, и наличие внешнего runtime-перевода — независимые вещи. Поэтому документация может существовать на языке, для которого в поставке нет соответствующего `.lang`.

Выбранный язык используется в меню, справке, сообщениях скрипта и записях журналов. Отдельной настройки языка для логов нет.

## Выбор языка

За выбор отвечает параметр `Language` в файле `option.cfg`. По умолчанию используется значение `auto`:

| Значение | Какой язык используется |
|---|---|
| `auto` | Язык определяется по локали ОС |
| `ru` | Встроенный русский |
| `en` | Встроенный английский |
| Другой двухбуквенный код, например `de` | Перевод из соответствующего файла, например `de.lang` |

Для постоянного выбора русского языка укажите в `option.cfg`:

```ini
Language=ru
```

Для отдельного запуска язык можно задать через CLI:

```bash
mikrotik-backup.sh --language=ru --help
```

Ключ `--language` имеет приоритет над настройкой в файле опций, но сам файл не изменяет. Код языка указывается двумя латинскими буквами без учёта регистра, либо используется `auto`.

### Автоматический выбор

При `auto` скрипт берёт первое непустое значение из `LC_ALL`, `LC_MESSAGES` и `LANG`, именно в таком порядке.

Например, `ru_RU.UTF-8` выбирает русский язык, а `de_DE.UTF-8` выбирает немецкий перевод из `de.lang`. При `C`, `C.UTF-8`, `POSIX` или невозможности определить язык используется английский.

Если выбранного внешнего перевода нет, сообщения также остаются английскими.

## Подключение внешнего перевода

В каталоге `lang/` находятся готовые внешние переводы `de.lang`, `es.lang`, `lv.lang`, `pl.lang` и `uk.lang`, а также канонический шаблон `en.lang`. Для использования внешнего перевода нужный файл следует скопировать из него в тот же каталог, где размещён `mikrotik-backup.sh`.

Например, для немецкого языка выполните в каталоге скрипта:

```bash
cp -- lang/de.lang de.lang
```

После этого выберите `de` в настройках либо укажите его при запуске:

```bash
mikrotik-backup.sh --language=de --help
```

Имя файла состоит из двух латинских букв и расширения `.lang`, например `de.lang`. Сам файл должен быть обычным читаемым файлом, а не символической ссылкой.

*(N.B. Каталог `lang/` служит для хранения набора переводов. Скрипт не подключает их оттуда автоматически: нужный файл должен находиться рядом с самим скриптом.)*

`en.lang` содержит все 245 ключей версии 2.3.1 и служит каноническим шаблоном для создания сторонних переводов. Он не заменяет встроенный английский и не участвует как внешний runtime-язык. Файл `ru.lang`, если его создать, также не заменит встроенный русский и будет проигнорирован.

## Выбор через «Редактор конфигурации»

Открываем редактор командой:

```bash
mikrotik-backup.sh -e
```

Переходим к строке выбора языка → нажимаем **Enter** до нужного значения → выбираем «Сохранить».

Варианты переключаются по кругу:

```text
auto → ru → en → найденные внешние языки по алфавиту → auto
```

Язык формы меняется сразу. До сохранения это предварительный просмотр, а «Отмена» возвращает прежний язык интерфейса. Если при запуске был указан `--language`, после выхода из редактора снова действует этот ключ.

Комментарии сохраняемого `option.cfg` записываются на языке, выбранном в самой настройке `Language`, а не по временному ключу CLI. При `auto` для них также используется локаль ОС.

Подробнее о работе редактора можно прочитать в [INTERACTIVE.md](INTERACTIVE.md).

## Создание и редактирование перевода

Если нужного Вам перевода пока нет, его можно подготовить самостоятельно. Возьмите `lang/en.lang` от той же версии скрипта и сохраните копию как `<xx>.lang`, где `xx` — двухбуквенный код нового языка. Шаблон версии 2.3.1 содержит все 245 ключей.

Сам формат простой: каждому сообщению соответствует отдельная строка. Например, в английском шаблоне:

```text
msg_version_en="MikroTik Backup Script"
msg_menu_title_en="Main menu"
```

В начале ключа стоит `msg_`, затем имя сообщения (`version`, `menu_title`) и суффикс языка `_en`.

Для нового языка замените суффикс `_en` на `_xx` во всех ключах и переведите только значения в кавычках. Имена сообщений не меняйте, а все placeholders сохраняйте точно. При исправлении существующего перевода достаточно изменить нужный текст справа от `=`.

Переводить сразу весь файл необязательно: отсутствующие сообщения будут показаны на английском. Произвольные новые ключи скрипт не использует.

### Правила записи

Файл сохраняется в UTF-8. Каждое значение заключается в двойные кавычки и должно быть непустым. Не добавляйте пробелы перед ключом, вокруг `=` или после закрывающей кавычки.

Для двойной кавычки внутри текста используется `\"`, для обратной косой черты `\\`. Другие экранирования, в том числе `\n` и `\t`, не поддерживаются. Знак `=` внутри кавычек допустим.

Пустые строки пропускаются. Комментарии форматом `.lang` не предусмотрены, а `#` внутри кавычек является частью текста. Окончания строк Windows (CRLF) и один BOM в начале файла поддерживаются.

Строка с ошибкой пропускается, остальные корректные переводы продолжают использоваться. Если одно сообщение указано несколько раз, действует последняя корректная запись. Управляющие символы и цветовые коды терминала в переводах не допускаются.

*(N.B. Файл локализации является текстовыми данными. Подстановка переменных и выполнение команд оболочки в нём не производятся.)*

### Подстановки в сообщениях

В некоторых строках встречаются значения в фигурных скобках, например:

```text
msg_log_batch_device_position_en="Processing device {index} of {total}"
```

При работе вместо `{index}` и `{total}` скрипт укажет номер устройства и общее количество устройств. Эти обозначения не переводятся: сохраняйте все подстановки исходной строки, каждую ровно один раз. Их положение внутри предложения можно менять.

Если подстановки нарушены, вместо такой строки будет использовано английское сообщение.

После сохранения файла проверьте перевод через справку и интерактивное меню с выбранным языком. Причины, по которым перевод не подключился, разобраны в разделе [Диагностика](TROUBLESHOOTING.md#language-problems).
