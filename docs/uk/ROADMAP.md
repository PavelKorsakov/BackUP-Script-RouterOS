## Версія 2.3.2

**Орієнтовна дата випуску: зима 2027 року.**

| Зміна | Очікуваний результат |
|---|---|
| Запуск без `option.cfg` | Відкривати головне інтерактивне меню замість негайного відкриття Configuration Editor |
| Короткі й довгі параметри | Додати відповідні довгі форми для коротких параметрів і, де можливо, короткі форми для довгих |
| Формат `devicelist.cfg` | Прибрати непотрібне поле «маркер пристрою» |
| Ім’я в дужках | Зробити виділення необов’язковим і дозволити використання повного імені |
