# Локалізація

[Зміст](../README_UK.md)

## Мова інтерфейсу та журналів

Російська (`ru`) й англійська (`en`) мови вбудовані в скрипт. Для них окремі файли перекладу не потрібні. З версією 2.3.1 постачаються зовнішні переклади інтерфейсу та журналів: `de.lang`, `es.lang`, `lv.lang`, `pl.lang` і `uk.lang`.

Мова документації та наявність зовнішнього runtime-перекладу — незалежні речі. Тому документація може бути доступна мовою, для якої в постачанні немає відповідного файла `.lang`.

Вибрана мова використовується в меню, довідці, повідомленнях скрипта та записах журналів. Окремого налаштування мови для журналів немає.

<br />

## Вибір мови

За вибір відповідає параметр `Language` у файлі `option.cfg`. Його стандартне значення — `auto`:

| Значення | Яка мова використовується |
|---|---|
| `auto` | Мова визначається за локаллю ОС |
| `ru` | Вбудована російська |
| `en` | Вбудована англійська |
| Інший дволітерний код, наприклад `de` | Переклад із відповідного файла, наприклад `de.lang` |

Щоб постійно використовувати російську, укажіть в `option.cfg`:

```ini
Language=ru
```

Для окремого запуску мову можна задати через CLI:

```bash
mikrotik-backup.sh --language=ru --help
```

Параметр `--language` має пріоритет над налаштуванням у файлі параметрів, але не змінює сам файл. Код мови задається двома латинськими літерами без урахування регістру; також можна використати `auto`.

### Автоматичний вибір

За `auto` скрипт бере перше непорожнє значення з `LC_ALL`, `LC_MESSAGES` і `LANG` саме в такому порядку.

Наприклад, `ru_RU.UTF-8` вибирає російську, а `de_DE.UTF-8` — німецький переклад із `de.lang`. Для `C`, `C.UTF-8`, `POSIX` або коли мову неможливо визначити, використовується англійська.

Якщо вибраного зовнішнього перекладу немає, повідомлення також залишаються англійськими.

## Підключення зовнішнього перекладу

У каталозі `lang/` містяться готові зовнішні переклади `de.lang`, `es.lang`, `lv.lang`, `pl.lang` і `uk.lang`, а також канонічний шаблон `en.lang`. Щоб використати зовнішній переклад, скопіюйте потрібний файл до каталогу, де розміщено `mikrotik-backup.sh`.

Наприклад, для німецької мови виконайте в каталозі скрипта:

```bash
cp -- lang/de.lang de.lang
```

Після цього виберіть `de` в налаштуваннях або вкажіть під час запуску:

```bash
mikrotik-backup.sh --language=de --help
```

Ім’я файла складається з двох латинських літер і розширення `.lang`, наприклад `de.lang`. Файл має бути звичайним читабельним файлом, а не символічним посиланням.

*(N.B. Каталог `lang/` призначено для зберігання набору перекладів. Скрипт не завантажує їх звідти автоматично: потрібний файл має бути поруч із самим скриптом.)*

`en.lang` містить усі 245 ключів версії 2.3.1 і є канонічним шаблоном для створення сторонніх перекладів. Він не замінює вбудовану англійську й не бере участі як зовнішня runtime-мова. Файл `ru.lang`, якщо його створити, також не замінить вбудовану російську й буде проігнорований.

## Вибір через Configuration Editor

Відкрийте редактор командою:

```bash
mikrotik-backup.sh -e
```

Перейдіть до рядка вибору мови → натискайте **Enter** до потрібного значення → виберіть «Зберегти».

Варіанти перемикаються по колу:

```text
auto → ru → en → знайдені зовнішні мови за абеткою → auto
```

Мова форми змінюється одразу. До збереження це лише попередній перегляд, а «Скасувати» повертає попередню мову інтерфейсу. Якщо під час запуску було вказано `--language`, після виходу з редактора цей параметр знову набирає чинності.

Коментарі у збереженому `option.cfg` записуються мовою, вибраною самим налаштуванням `Language`, а не тимчасовим параметром CLI. За `auto` для них також використовується локаль ОС.

Докладніше про роботу редактора читайте в [INTERACTIVE.md](INTERACTIVE.md).

## Створення та редагування перекладу

Якщо потрібного перекладу ще немає, його можна підготувати самостійно. Візьміть `lang/en.lang` тієї самої версії скрипта й збережіть копію як `<xx>.lang`, де `xx` — дволітерний код нової мови. Шаблон версії 2.3.1 містить усі 245 ключів.

Формат простий: кожному повідомленню відповідає окремий рядок. Наприклад, в англійському шаблоні:

```text
msg_version_en="MikroTik Backup Script"
msg_menu_title_en="Main menu"
```

На початку ключа стоїть `msg_`, далі — ім’я повідомлення (`version`, `menu_title`) і суфікс мови `_en`.

Для нової мови замініть суфікс `_en` на `_xx` в усіх ключах і перекладіть лише значення в лапках. Імена повідомлень не змінюйте, а всі placeholders збережіть точно. Щоб виправити наявний переклад, достатньо змінити потрібний текст праворуч від `=`.

Перекладати весь файл одразу не обов’язково: відсутні повідомлення показуватимуться англійською. Довільні нові ключі скрипт не використовує.

### Правила запису

Збережіть файл у UTF-8. Кожне значення має бути непорожнім і взятим у подвійні лапки. Не додавайте пробілів перед ключем, навколо `=` або після кінцевої лапки.

Для подвійної лапки всередині тексту використовуйте `\"`, для зворотної скісної риски — `\\`. Інші екранування, зокрема `\n` і `\t`, не підтримуються. Символ `=` усередині лапок дозволено.

Порожні рядки пропускаються. Формат `.lang` не передбачає коментарів, а `#` усередині лапок є частиною тексту. Підтримуються закінчення рядків Windows (CRLF) і один BOM на початку файла.

Рядок із помилкою пропускається, а інші коректні переклади продовжують використовуватися. Якщо те саме повідомлення вказано кілька разів, діє останній коректний запис. Керівні символи й колірні коди термінала в перекладах заборонено.

*(N.B. Файл локалізації обробляється як текстові дані. Підстановлення змінних і виконання команд оболонки з нього не відбуваються.)*

### Підстановки в повідомленнях

Деякі рядки містять значення у фігурних дужках, наприклад:

```text
msg_log_batch_device_position_en="Processing device {index} of {total}"
```

Під час роботи скрипт замінює `{index}` і `{total}` номером пристрою та загальною кількістю пристроїв. Ці позначення не перекладаються: збережіть кожну підстановку з початкового рядка рівно один раз. Її розташування в реченні можна змінювати.

Якщо підстановки порушено, замість такого рядка буде використано англійське повідомлення.

Після збереження файла перевірте переклад у довідці та інтерактивному меню з вибраною мовою. Причини, через які переклад міг не підключитися, описано в розділі [Діагностика](TROUBLESHOOTING.md#language-problems).
