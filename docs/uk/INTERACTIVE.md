# Інтерактивний інтерфейс

[Зміст](../README_UK.md)

## Головне меню

Через головне меню можна налаштувати скрипт, створити резервні копії, підготувати список пристроїв або відкрити вбудовану довідку. Щоб викликати його, запустіть:

```bash
mikrotik-backup.sh -i
```

| Пункт | Що відкривається або виконується |
|---|---|
| `1` | BackUP Master для роботи з одним пристроєм |
| `2` | Пакетне резервне копіювання за списком пристроїв |
| `3` | Configuration Editor для створення або зміни `option.cfg` |
| `4` | Довідка щодо параметрів CLI |
| `5` | Інструкція з використання скрипта |
| `6` | Вихід до консолі |

Пункт `2` з’являється, коли `devicelist.cfg` містить принаймні один придатний запис. Якщо списку ще немає або в ньому немає відповідних пристроїв, цей пункт не показується. Номери інших пунктів не змінюються.

Після пакетного копіювання буде показано результат, а потім скрипт поверне вас до консолі.

*(N.B. Запуск без параметрів не відкриває головне меню. Якщо `option.cfg` немає або в ньому немає придатних налаштувань, відкриється Configuration Editor; якщо налаштування підготовлено, скрипт перейде до пакетного копіювання.)*

## Керування

Переміщуйтеся пунктами стрілками **вгору** і **вниз**, а потрібний пункт вибирайте клавішею **Enter**. Якщо біля дії вказано номер, її також можна вибрати відповідною цифровою клавішею.

У Configuration Editor і BackUP Master над списком показується опис вибраного поля. Якщо всі рядки не вміщаються у вікні термінала, список прокручується під час руху стрілками. Заголовок і опис залишаються видимими, а вибраний рядок не виходить за межі вікна.

Пункти збереження, виконання та виходу розташовано наприкінці того самого списку. Затемнені рядки недоступні за вибраних налаштувань і пропускаються під час навігації.

Для роботи потрібні термінал і утиліта `stty`. І стандартне введення, і стандартне виведення мають бути пов’язані з терміналом. Основні екрани потребують ширини щонайменше 46 стовпців, а вбудована інструкція — 80. Якщо вікно замале, скрипт повідомить про помилку `31`; збільште вікно й повторіть запуск.

## Configuration Editor

Відкрити редактор можна через пункт `3` головного меню або безпосередньо командою:

```bash
mikrotik-backup.sh -e
```

Якщо `option.cfg` уже підготовлено, форму буде заповнено вашими налаштуваннями. Якщо файла ще немає, використовуються стандартні значення.

У редакторі вибираються мова, джерело списку пристроїв, параметри резервних копій, сховище, щомісячне архівування та журналювання. Призначення параметрів і допустимі значення описано в [OPTIONS.md](OPTIONS.md).

### Зміна налаштувань

Перемикачі «Так / Ні», тип резервної копії, формат експорту й рівень журналу змінюються натисканням **Enter** на відповідному рядку. Для шляху або дня щомісячного архівування відкривається введення значення.

Поле «Використовувати інкрементне порівняння» (`UseIncremental`) розташовано одразу після типу резервної копії. «Так» вмикає порівняння, «Ні» залишає кожну нову справну копію без порівняння з попередньою.

Для щомісячного архівування вкажіть `false`, щоб вимкнути його, або число від `1` до `28`. У формі вимкнений стан показується як «Ні», а ввімкнений — як вибране число місяця.

Поля, які не стосуються вибраного режиму, затемнюються. Наприклад, якщо створюється лише `.rsc`, недоступні шифрування бінарної копії та очищення перед нею; якщо вибрано лише `.backup`, недоступні параметри текстового експорту. Після такого перемикання непридатні параметри повертаються до стандартних значень.

Пароль шифрування вводиться й показується зірочками.

### Збереження та скасування

Виберіть потрібні параметри → перейдіть до «Зберегти» → натисніть **Enter**. Файл `option.cfg` буде створено або перезаписано з вибраними налаштуваннями.

До збереження зміни містяться лише в пам’яті. Пункт «Скасувати» залишає попередній файл без змін. Якщо ви вже щось змінили, редактор попросить підтвердити відмову від цих змін.

Редактор, відкритий із головного меню, повертає до нього. Після окремого запуску через `-e` закриття редактора повертає до консолі.

*(N.B. `SshPort`, `IgnoreOxiAccess`, `encrypt_type`, `Login` і `Password` у формі не показуються. Їхні налаштування та правила збереження описано в [OPTIONS.md](OPTIONS.md).)*

### Вибір мови

У рядку мови кожне натискання **Enter** вибирає наступний варіант:

```text
auto → ru → en → знайдені зовнішні мови за абеткою → auto
```

Мова форми змінюється одразу, щоб можна було переглянути результат. «Зберегти» записує вибрану мову до `option.cfg`, а скасування повертає попередню мову інтерфейсу. Якщо під час запуску явно вказано `--language`, після виходу з редактора цей параметр знову набирає чинності.

Підключення зовнішніх перекладів описано в [LOCALIZATION.md](LOCALIZATION.md).

## BackUP Master

BackUP Master дає змогу заповнити параметри одного пристрою, створити його копії, зберегти пристрій до списку або підготувати команду для запуску з консолі.

Виберіть пункт `1` головного меню або запустіть:

```bash
mikrotik-backup.sh -b
```

На відміну від Configuration Editor, BackUP Master не заповнює звичайні поля налаштуваннями з `option.cfg`. Значення беруться з вбудованих налаштувань і параметрів, явно переданих через CLI. Виняток — `UseIncremental`: його значення береться з файла параметрів, а якщо налаштування немає, використовується `true`.

Наявні записи з `devicelist.cfg` до форми також не завантажуються. Ім’я, адресу, логін і пароль потрібно заповнити для вибраного пристрою.

### Поля BackUP Master

Поля розташовано в наведеному нижче порядку. Тут подано їхні назви в українському перекладі:

| Поле | Призначення |
|---|---|
| Ім’я пристрою | Ім’я для списку пристроїв і резервних копій, якщо отримання RouterOS Identity вимкнено |
| IP-адреса | IP-адреса або DNS-ім’я пристрою |
| Логін | Користувач пристрою RouterOS |
| Пароль | Пароль пристрою RouterOS |
| SSH-порт | Порт підключення; стандартне значення `22` |
| Тип резервної копії | Конфігурація `.rsc`, бінарна копія `.backup` або обидва формати |
| Використовувати інкрементне порівняння | Порівнювати нову копію з попередньою або зберігати без порівняння |
| Формат експорту | `compact`, `terse` або `verbose` |
| Чутливі дані | Додавати чутливі значення до текстового експорту |
| Пароль шифрування | Шифрувати бінарну копію; порожнє значення вимикає шифрування |
| Очищення DNS-кешу | Очистити DNS-кеш перед бінарною копією |
| Очищення історії консолі | Очистити історію консолі перед бінарною копією |
| Каталог резервних копій | Каталог для збереження файлів |
| Це мережевий каталог | Значення `UseNetFolder`; перевірка монтування застосовується в пакетному режимі |
| Використовувати RouterOS Identity | Отримувати ім’я з пристрою замість указаного у формі |

Перемикачі, тип копії та формат експорту змінюються через **Enter**, інші значення вводяться у відповідних полях. Обидва паролі приховано зірочками.

**Зверніть увагу!!!**
За замовчуванням увімкнено чутливі дані в текстовому експорті, очищення DNS-кешу та історії консолі перед бінарною копією. Перед виконанням виберіть потрібні налаштування.

У BackUP Master немає пунктів для `MonthlyArchive`, `LogLevel` і `MainLogPath`. Щомісячне архівування під час виконання через BackUP Master вимкнено, а налаштування журналювання беруться з `option.cfg` з урахуванням переданих параметрів CLI.

### 1. Виконати резервне копіювання

Заповніть адресу, логін і пароль, перевірте порт і параметри копії → виберіть «1. Виконати резервне копіювання».

Якщо отримання RouterOS Identity ввімкнено, ім’я для копій буде взято з пристрою. Якщо цю можливість вимкнено, потрібно заповнити поле «Ім’я пристрою».

Почнеться резервне копіювання одного пристрою. Після завершення буде показано результат із кодом, а скрипт поверне вас до консолі. До форми BackUP Master він уже не повертається незалежно від успіху або помилки.

Розташування файлів і правила зберігання описано в [BACKUPS.md](BACKUPS.md), а повідомлення про виконання — у [LOGGING.md](LOGGING.md).

### 2. Зберегти пристрій у devicelist.cfg

Для збереження потрібні ім’я пристрою, адреса, логін, пароль і SSH-порт. Доки потрібні поля не заповнено, відповідна дія недоступна.

BackUP Master створить файл, додасть новий запис або оновить наявний запис із тим самим іменем. У разі конфлікту записів або помилки збереження попередній список залишається без змін. Після збереження форма залишається відкритою.

**До `devicelist.cfg` зберігаються лише дані пристрою.** Параметри копіювання з форми не записуються до `option.cfg`, і ця дія не запускає резервне копіювання.

*(N.B. Порт `22` зберігається як порожнє поле. Під час наступного пакетного запуску такий запис використовує `SshPort` із налаштувань скрипта. Нестандартний порт записується явно.)*

Формат списку та правила оновлення описано в [DEVICES.md](DEVICES.md).

### 3. Скопіювати консольну команду

BackUP Master підготує команду запуску на основі заповненої форми й передасть її до буфера обміну. Резервне копіювання не почнеться, а робота BackUP Master завершиться поверненням до консолі.

Для цієї можливості потрібні GNU `base64` із підтримкою `--wrap=0` і підтримка OSC 52 вашим терміналом. Якщо використовується термінальний мультиплексор, він також має пропускати цю команду. Якщо передавання до буфера не підтримується, команда не виводиться на екран відкритим текстом.

Параметри, що збігаються з вбудованими значеннями, можуть не потрапити до команди. Під час її наступного запуску налаштування з `option.cfg` продовжують діяти, тому результат може відрізнятися від виконання безпосередньо через BackUP Master.

Налаштування `UseIncremental` до команди не переноситься: для нього немає окремого параметра CLI. Під час запуску скопійованої команди значення береться з `option.cfg` або зі стандартних налаштувань.

*(N.B. Команда в буфері обміну містить паролі. Ураховуйте це під час використання історії буфера та вставлення команди в оболонку. Докладніше дивіться в [SECURITY.md](SECURITY.md).)*

### 0. Повернутися до Головного меню

Результат залежить від того, звідки відкрито BackUP Master:

| Спосіб відкриття | Куди відбудеться повернення |
|---|---|
| Через головне меню `-i` | До головного меню |
| Окремим запуском `-b` | До консолі |

Незбережені параметри форми відкидаються. Уже збережений запис у `devicelist.cfg` залишається.

## Довідка та інструкція

Пункт `4` головного меню відкриває довідку щодо параметрів командного рядка, а пункт `5` — коротку інструкцію з роботи скрипта.

Якщо текст не вміщується за висотою, він ділиться на сторінки. Гортайте їх клавішами **PageUp / PageDown**; номер поточної сторінки показується на екрані.

Пункт `0` повертає до головного меню, а пункт `6` завершує роботу скрипта. Ці дії можна вибрати стрілками та **Enter** або відповідною цифрою.

Ту саму довідку щодо CLI можна отримати безпосередньо в консолі:

```bash
mikrotik-backup.sh -h
```
