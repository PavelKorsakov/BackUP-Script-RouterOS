## Versão 2.3.2

**Data de lançamento prevista: Inverno 2027.**

| Alteração | Resultado previsto |
|---|---|
| Executar sem `option.cfg` | Abrir o menu interativo principal em vez de abrir imediatamente o Editor de Configuração |
| Opções curtas e longas | Adicionar formas longas correspondentes para opções curtas e, sempre que possível, formas curtas para opções longas |
| Formato `devicelist.cfg` | Remover o campo desnecessário “marcador de dispositivo” |
| Nome entre parênteses | Tornar a extração opcional e permitir que o nome completo seja usado |
