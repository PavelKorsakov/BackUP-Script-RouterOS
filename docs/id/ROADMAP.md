## Versi 2.3.2

**Perkiraan tanggal rilis: musim dingin 2027.**

| Perubahan | Hasil yang direncanakan |
|---|---|
| Eksekusi tanpa `option.cfg` | Membuka menu interaktif utama alih-alih langsung membuka Editor Konfigurasi |
| Opsi pendek dan panjang | Menambahkan bentuk panjang yang sesuai untuk opsi pendek dan, jika memungkinkan, bentuk pendek untuk opsi panjang |
| Format `devicelist.cfg` | Menghapus kolom “penanda perangkat” yang tidak diperlukan |
| Nama dalam tanda kurung | Menjadikan ekstraksi opsional dan memungkinkan penggunaan nama lengkap sebagai gantinya |
