## Version 2.3.2

**Estimated release date: winter 2027.**

| Change | Intended result |
|---|---|
| Run without `option.cfg` | Open the main interactive menu instead of opening the Configuration Editor immediately |
| Short and long options | Add corresponding long forms for short options and, where possible, short forms for long options |
| `devicelist.cfg` format | Remove the unnecessary “device marker” field |
| Name in parentheses | Make extraction optional and allow the full name to be used instead |
